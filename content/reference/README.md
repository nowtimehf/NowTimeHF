# Reference Material

Past posts, visual style examples, and strategy notes worth reusing.

The content commands read this folder as **examples to imitate**, second only to
`brand/brief.md`. The brief says what the voice *is*; the files here show what it
actually looks like in practice. When they disagree, the brief wins — but a
concrete example beats an abstract rule, so keep the strongest work here.

## What to put here

| File | Holds |
|---|---|
| `past-posts.md` | Posts that performed well or nailed the voice. Include the platform and, where known, how they did. |
| `visual-style.md` | Image/graphic direction: colors, typography, photo vs. illustration, layout patterns, example image prompts. |
| `strategy-notes.md` | Positioning language, objection handling, offer framing, anything that shaped how the brand talks. |

Anything else in this folder gets picked up too — these are just the defaults the
commands look for first.

## Format

No strict schema. Label each excerpt with its platform and date where you can:

```markdown
## LinkedIn — 2026-07-14 — Business Case
[full post text]
Notes: strongest performer that month; the per-headcount math is what landed.
```

The more verbatim the text, the more useful it is — paraphrases teach voice poorly.
